# Clean Way OS — Customer Onboarding Prototype

This is a working, responsive, two-screen onboarding web app with the supplied Clean Way logo. No external libraries or internet connection are required for the local prototype.

## Run

Open `index.html` in a browser. For an iPad, host this folder on a web server and open its URL in Safari. A simple development server can be started with `python -m http.server 8080` from this folder.

## Integrate with existing Clean Way OS

This is a **standalone prototype**, not yet committed to or connected with the existing GitHub repository or Supabase project. To integrate it into the existing app, share the current app source files or repository access. The welcome and About views can then be converted into the project's existing framework/components.
